# lost_and_found
-
OBJETIVO DO SITE: 
O *CADÊ MEU?* é um site desenvolvido com o intuito de facilitar o processo de *registro, localização e devolução de objetos perdidos ou encontrados dentro do ambiente escolar*. A plataforma permite que alunos cadastrem informações sobre objetos, como nome, descrição, local e data em que foram perdidos ou encontrados, além de disponibilizar os dados necessários para facilitar o contato entre os estudantes.

O principal objetivo é *organizar os achados e perdidos da escola de forma prática, rápida e acessível*, evitando que objetos encontrados sejam esquecidos ou que alunos tenham dificuldade para localizar seus pertences. Dessa forma, o site contribui para uma maior organização no ambiente escolar e incentiva a colaboração e a responsabilidade entre os estudantes.
